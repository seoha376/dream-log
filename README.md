# Dream Log

Dream Log is an intelligent personal dream journal application.

## Team

- Song Seoha
- Eungyeol Kim
- Mingyeong Kim

## Tech Stack

- Frontend: React + Vite
- Backend: Node.js + Express
- Database: SQLite
- Auth: JWT + bcrypt
- AI: OpenAI API

## Project Structure

```txt
dream-log/
├─ frontend/
├─ backend/
├─ docs/
│  ├─ api/
│  └─ db/
├─ README.md
├─ .gitignore
└─ .env.example
```

## Run

# Run Frontend

cd frontend
npm install
npm run dev

# Run Backend

cd backend
npm install
npm run dev

GET http://localhost:3000/health
